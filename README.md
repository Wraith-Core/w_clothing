# w_clothing · متجر الملابس والخزانة

## الإصدار 1.0.0 — 2026-11-21

سكربت مستقل لمتاجر الملابس والخزائن والبدلات المحفوظة (Outfits) وحالات الملابس (خلع القبعة، تشمير الأكمام، رفع الوشاح...) يعمل على `w_core` و`VORP` و`RSG` و`QBR` بشكل مستقل تمامًا، ويتكامل تلقائيًا مع `w_creators` عند وجوده دون أي تعارض أو فقدان لملابس اللاعبين.

### الميزات
- **متاجر الملابس:** كتالوج تفاعلي، غرفة قياس معزولة، تسعير لكل فئة أو موديل، دفع بالنقد أو الذهب، تلوين الملابس مع حفظ الألوان المملوكة (Colourways)، إعادة البيع (اختياري)، وساعات عمل وصلاحيات وظائف/ACE.
- **الخزانة والبدلات المحفوظة (Wardrobe & Outfits):** ارتداء الملابس المملوكة مجانًا، حفظ وتحديث وتسمية وحذف البدلات، دعم خزائن المنازل مع `w_housing`، وخيار لف الملابس كأغراض في الحقيبة (`Config.Clothing.items`).
- **حالات الملابس:** أمر `/clothing` وتكامل مباشر مع عجلة الملابس `w_clothingwheel` وعجلة `w_wheel`.
- **لوحة الإدارة:** `/clothingadmin` لإضافة وتعديل متاجر الملابس والخزائن داخل اللعبة (مع وضع البوت ومكان القياس وكتاب الأزياء).

### التشغيل
```cfg
ensure w_lib
ensure w_clothing
ensure w_clothingwheel # اختياري: عجلة الملابس بضغطة F1
```
الصلاحية الإدارية للوحة: `w_clothing.admin` (وتقبل أيضًا `w_creators.admin` تلقائيًا).
